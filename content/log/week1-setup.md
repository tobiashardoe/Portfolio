## Hvad er implementeret?

Portfolioen er sat op med Hugo og GitHub Pages. JPA-entiteter og DAO-klasser giver CRUD, og UserDAO og TicketDAO har otte tests.

## Hvorfor denne løsning?

Ticketsystemet kan udvides gradvist. DAO-laget holder databasearbejdet samlet.

## Hvad har jeg lært?

Jeg har lært om JPA, CRUD og opsætning af Hugo og GitHub Pages.

## Udfordringer
